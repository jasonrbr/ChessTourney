# ChessTourney Diagrams

These diagrams translate the current planning artifacts into visual form for easier review.

## Format

The diagrams are written in Mermaid so they remain:

- text-based and versionable
- easy to revise during planning
- easy to render to SVG or PNG for sharing
- easy to recreate or refine on a whiteboard or Miro board

## Included Diagrams

- `system-context.mmd`
- `application-architecture.mmd`
- `domain-model.mmd`
- `role-permission-map.mmd`
- `player-registration-workflow.mmd`
- `tournament-creation-publishing-workflow.mmd`
- `event-operations-workflow.mmd`
- `reporting-export-submission-workflow.mmd`
- `integration-boundary.mmd`

## Suggested Board Layout

If you move these onto a Miro board, a good frame layout is:

1. System context
2. Application architecture
3. Domain model
4. Role and permission map
5. Open questions

## Notes

- These diagrams reflect the current planning phase and are not implementation-final.
- The diagrams intentionally simplify some details so the big picture stays readable.
- Open modeling questions from `DomainModel.md` are still unresolved and should remain visible during review.
